## 🎯 OIDC是什么？（一句话讲明白）

**OIDC** 就像一个"万能钥匙"：
- 用户不用在你这里注册账号
- 用户可以用微信、QQ、GitHub等已有账号直接登录你的网站
- 你也不用操心密码安全问题
- 就像"用微信登录xxx"一样简单！

## 🚀 5分钟快速上手（超级简单！）

### 第1步：引入文件

在你的HTML文件中，加入这两行代码：

```html
<!-- 引入样式文件 -->
<link rel="stylesheet" href="oidc.css">

<!-- 引入JS文件 -->
<script src="oidc.js"></script>
```

就这么简单！像引入jQuery一样容易～

---

### 第2步：找个地方放登录按钮

在你的页面上找一个合适的位置（比如登录框的位置），加个容器：

```html
<div id="oidc-login"></div>
```

这个 `<div>` 就是给登录按钮预留的位置。

---

### 第3步：初始化配置

在页面的 `<script>` 标签里，加上这段代码：

```javascript
// 初始化OIDC，填入你的App Key
oidc.init('你的App Key', {
    el: '#oidc-login',  // 刚才创建的容器ID
    logLevel: 'info'    // 可以看到日志信息，方便调试
});
```

**等等！App Key从哪里来？**

别担心，你需要先去 `oidc.org.cn` 注册一个账号，然后创建一个应用，就能拿到App Key了！就像申请微信公众号的AppID一样～

---

### 第4步：加载登录按钮

现在，让我们加载登录按钮：

```javascript
oidc.load('你的App Key', function(ospList) {
    console.log('登录按钮加载成功啦！', ospList);
});
```

就这么简单！刷新页面，你就能看到漂亮的登录按钮了！🎉

## 📱 Vue用户看这里！（超简单！）

如果你用的是Vue，那更简单了！

### Vue 3 最简单的用法：

```html
<template>
  <div>
    <h1>Vue 3 + OIDC</h1>
    <Oidc 
      app-key="你的App Key" 
      @success="onLoginSuccess"
    />
  </div>
</template>

<script setup>
import { Oidc } from './oidc.vue.js';

const onLoginSuccess = (data) => {
  console.log('登录成功！', data);
};
</script>
```

## 🔍 登录成功后，我能拿到什么？

当用户点击登录按钮并成功登录后，你会收到这样的数据：

```javascript
oidc.init('你的App Key', {
    el: '#oidc-login',
    success: function(data) {
        console.log('登录成功！', data);
        // data包含：用户ID、昵称、头像等信息
    }
});
```

你可以用这些信息：
- 把用户信息存到你的数据库
- 设置登录状态
- 跳转到用户中心

## ⚡ 高级功能（进阶玩家看这里）

### 功能1：自定义回调函数

```javascript
oidc.init('你的App Key', {
    el: '#oidc-login',
    
    // 登录成功的回调
    success: function(data) {
        alert('登录成功！欢迎 ' + data.nickname);
        // 这里可以跳转到主页
    },
    
    // 登录失败的回调
    fail: function(error) {
        alert('登录失败了：' + error.message);
    },
    
    // 取消登录的回调
    cancel: function() {
        console.log('用户取消了登录');
    }
});
```

---

### 功能2：动态修改配置

想换个样式？不用刷新页面！

```javascript
// 改成卡片模式
oidc.config({
    uiType: 'card'
});

// 刷新显示
oidc.refresh();
```

---

### 功能3：预加载（更快！）

如果你想让按钮加载得更快，可以预加载数据：

```javascript
// 在页面加载时就预加载
window.addEventListener('load', function() {
    oidc.preload('你的App Key');
});

// 稍后再显示
setTimeout(function() {
    oidc.load('你的App Key', function(list) {
        console.log('数据早就准备好了！');
    });
}, 1000);
```

## 🔧 常见问题解答（FAQ）

### Q1：为什么登录按钮没有显示出来？

**答**：请检查以下几点：
1. ✅ `oidc.js` 和 `oidc.css` 文件路径对不对？
2. ✅ App Key 有没有填对？
3. ✅ 浏览器控制台（按F12）有没有报错？
4. ✅ 有没有用 `http://` 访问页面（不能直接双击打开HTML文件）？

---

### Q2：怎么拿到App Key？

**答**：
1. 访问 `oidc.org.cn`
2. 注册账号并登录
3. 创建一个新应用
4. 就能看到你的App Key了！

---

### Q3：生产环境用哪个文件？

**答**：为了让网页加载更快，生产环境建议用压缩后的文件：

| 文件类型 | 开发环境 | 生产环境 |
|----------|----------|----------|
| JS文件 | `oidc.js` | `oidc.mn.js` |
| Vue文件 | `oidc.vue.js` | `oidc.vue.mn.js` |
| CSS文件 | `oidc.css` | `oidc.mn.css` |

压缩后的文件更小，加载更快！🚀

---

### Q4：可以用HTTPS吗？

**答**：当然可以！默认会自动检测：

```javascript
// 自动检测（推荐）
oidc.init('你的App Key');

// 或者强制使用HTTPS
oidc.init('你的App Key', {
    https: true
});

// 强制使用HTTP
oidc.init('你的App Key', {
    https: false
});
```
